Hilfe

Dateien sichern

Bewahren Sie eine Kopie Ihrer Fotos und Dokumente auf einem USB-Laufwerk auf.

  1. Schließen Sie ein USB-Laufwerk oder eine externe Festplatte an.
  2. Öffnen Sie Kyrofix Backup und wählen Sie die Ordner. Dokumente, Desktop und Bilder sind schon ausgewählt.
  3. Wählen Sie das USB-Laufwerk und klicken Sie auf Back up now.

Dateien zurückholen

Öffnen Sie Kyrofix Backup, klicken Sie auf Restore, wählen Sie die Sicherung und den Zielort.
