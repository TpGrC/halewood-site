Offline auf dem Handy spielen

Legen Sie ein Halewood-Spiel auf den Startbildschirm, damit es wie eine App startet.

iPhone

  1. Öffnen Sie das Spiel in Safari.
  2. Tippen Sie auf Teilen, dann auf Zum Home-Bildschirm.

Android

  1. Öffnen Sie das Spiel in Chrome.
  2. Tippen Sie auf das Menü (drei Punkte), dann App installieren oder Zum Startbildschirm hinzufügen.

Einmal mit Internet öffnen, danach läuft es offline. Münzen und Fortschritt bleiben auf Ihrem Handy.
