Eine Kyrofix-App installieren

Jede Kyrofix-App unter Windows 10 oder 11 herunterladen, installieren und öffnen.

  1. Öffnen Sie die Seite der App, zum Beispiel Kyrofix Driver Updater, und klicken Sie auf Herunterladen.
  2. Öffnen Sie die heruntergeladene Datei. Zeigt Windows „Der Computer wurde durch Windows geschützt“, klicken Sie auf Weitere Informationen und dann Trotzdem ausführen. Das passiert bei neuen Apps kleiner Studios.
  3. Klicken Sie auf Install. Kein Admin-Passwort nötig.
  4. Die App öffnet sich von selbst. Sie finden sie auch im Startmenü.

Entfernen

Öffnen Sie Windows-Einstellungen, dann Apps, suchen Sie die Kyrofix-App und klicken Sie auf Deinstallieren.
