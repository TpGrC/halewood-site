Was ist eine XRechnung?

Die XRechnung ist das deutsche Format für elektronische Rechnungen nach der europäischen Norm EN 16931. Die Rechnung besteht aus einer XML-Datei, die das Buchhaltungsprogramm Ihres Kunden automatisch lesen kann. Ein Mensch sieht darin zunächst nur Code – deshalb gibt es Programme, die sie als normale Rechnung anzeigen.

In 3 Schritten zur XRechnung

1. Firmendaten einmal eintragen

Öffnen Sie Halewood E-Rechnung und tragen Sie unter „Mein Unternehmen“ Ihre Daten ein. Sie werden gespeichert.

2. Rechnung ausfüllen

Kunde, Käuferreferenz und Positionen eingeben. Netto, Umsatzsteuer und Gesamtbetrag werden automatisch berechnet.

3. XML herunterladen und senden

Mit „XRechnung herunterladen“ erhalten Sie die fertige Datei. Senden Sie sie per E-Mail – gern zusammen mit einer PDF zum Ansehen.

Häufige Fragen

Was ist der Unterschied zwischen XRechnung und ZUGFeRD?

Die XRechnung ist eine reine XML-Datei. ZUGFeRD ist eine PDF, in der die XML-Daten eingebettet sind. Beide Formate erfüllen die E-Rechnungspflicht, wenn sie der Norm EN 16931 entsprechen.

Brauche ich eine Leitweg-ID?

Nur bei Rechnungen an öffentliche Auftraggeber. Bei Firmenkunden tragen Sie stattdessen eine Käuferreferenz ein, zum Beispiel Kunden- oder Bestellnummer.
