Jouer hors ligne sur votre téléphone

Ajoutez un jeu Halewood à l’écran d’accueil pour l’ouvrir comme une appli.

iPhone

  1. Ouvrez le jeu dans Safari.
  2. Touchez Partager, puis Sur l’écran d’accueil.

Android

  1. Ouvrez le jeu dans Chrome.
  2. Touchez le menu (trois points), puis Installer l’appli ou Ajouter à l’écran d’accueil.

Ouvrez-le une fois avec Internet. Ensuite, il fonctionne hors ligne. Vos pièces et votre progression restent sur le téléphone.
