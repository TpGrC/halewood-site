Installer une appli Kyrofix

Téléchargez, installez et ouvrez n’importe quelle appli Kyrofix sous Windows 10 ou 11.

  1. Ouvrez la page de l’appli, par exemple Kyrofix Driver Updater, et cliquez sur Télécharger.
  2. Ouvrez le fichier téléchargé. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même. Cela arrive avec les nouvelles applis de petits studios.
  3. Cliquez sur Install. Aucun mot de passe administrateur requis.
  4. L’appli s’ouvre toute seule. Vous la trouverez aussi dans le menu Démarrer.

Désinstaller

Ouvrez les Paramètres Windows, puis Applications, trouvez l’appli Kyrofix et cliquez sur Désinstaller.
