« Windows a protégé votre ordinateur »

Pourquoi ce message apparaît et que faire.

Windows affiche ce message bleu pour les applis récentes ou encore peu téléchargées. Cela ne veut pas dire que l’appli est dangereuse.

  1. Cliquez sur Informations complémentaires.
  2. Vérifiez que l’éditeur ou le nom du fichier indique Kyrofix.
  3. Cliquez sur Exécuter quand même.

Ne téléchargez Kyrofix que sur halewoodsystems.com. Si vous l’avez eu ailleurs, supprimez-le.
