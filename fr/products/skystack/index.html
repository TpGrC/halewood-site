Sur iPhone : ouvre le jeu dans Safari, touche Partager puis « Sur l’écran d’accueil ». Sur Android : menu de Chrome puis « Installer l’application ».

Questions

C’est gratuit ?

Oui. Tous les niveaux sont gratuits. Les pubs facultatives donnent des pièces, des aides ou une seconde chance.

Faut-il télécharger quelque chose ?

Non. Il se joue dans le navigateur du mobile ou de l’ordinateur. Pour le garder sur ton mobile, choisis « Sur l’écran d’accueil » dans Safari ou « Installer l’application » dans Chrome.

Ma progression est-elle enregistrée ?

Oui, sur ton appareil, dans le navigateur. Effacer les données du navigateur la remet à zéro.

Ça marche hors ligne ?

Oui, après l’avoir ouvert une fois.
