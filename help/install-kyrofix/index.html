Install a Kyrofix app

Download, install and open any Kyrofix app on Windows 10 or 11.

  1. Open the app's page, for example Kyrofix Driver Updater, and click Download.
  2. Open the downloaded file. If Windows shows "Windows protected your PC", click More info, then Run anyway. This happens with new apps from small studios.
  3. Click Install. No admin password is needed.
  4. The app opens by itself. You will also find it in the Start menu.

Remove it

Open Windows Settings, then Apps, find the Kyrofix app and click Uninstall.
