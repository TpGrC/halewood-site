"Windows protected your PC"

Why you see this message and what to do.

Windows shows this blue message for apps that are new or not downloaded by many people yet. It does not mean the app is harmful.

  1. Click More info.
  2. Check that the publisher or file name says Kyrofix.
  3. Click Run anyway.

Only download Kyrofix from halewoodsystems.com. If you got it anywhere else, delete it.
