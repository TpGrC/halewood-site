Fai il backup dei file

Tieni una copia di foto e documenti su una chiavetta USB.

  1. Collega una chiavetta USB o un disco esterno.
  2. Apri Kyrofix Backup e scegli le cartelle. Documenti, Desktop e Immagini sono già selezionati.
  3. Scegli la chiavetta USB e clicca Back up now.

Recuperare i file

Apri Kyrofix Backup, clicca Restore, scegli il backup e dove salvare i file.
