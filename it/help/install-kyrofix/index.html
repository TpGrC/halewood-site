Installare un’app Kyrofix

Scarica, installa e apri qualsiasi app Kyrofix su Windows 10 o 11.

  1. Apri la pagina dell’app, per esempio Kyrofix Driver Updater, e clicca Scarica.
  2. Apri il file scaricato. Se Windows mostra «PC protetto da Windows», clicca Ulteriori informazioni, poi Esegui comunque. Succede con le app nuove dei piccoli studi.
  3. Clicca Install. Nessuna password di amministratore.
  4. L’app si apre da sola. La trovi anche nel menu Start.

Disinstallare

Apri le Impostazioni di Windows, poi App, trova l’app Kyrofix e clicca Disinstalla.
