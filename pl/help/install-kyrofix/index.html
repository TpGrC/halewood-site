Instalacja aplikacji Kyrofix

Pobierz, zainstaluj i otwórz dowolną aplikację Kyrofix w Windows 10 lub 11.

  1. Otwórz stronę aplikacji, np. Kyrofix Driver Updater, i kliknij Pobierz.
  2. Otwórz pobrany plik. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij Więcej informacji, a potem Uruchom mimo to. Tak bywa z nowymi aplikacjami małych studiów.
  3. Kliknij Install. Hasło administratora nie jest potrzebne.
  4. Aplikacja otworzy się sama. Znajdziesz ją też w menu Start.

Odinstalowanie

Otwórz Ustawienia Windows, potem Aplikacje, znajdź aplikację Kyrofix i kliknij Odinstaluj.
