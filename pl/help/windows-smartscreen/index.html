„System Windows ochronił ten komputer”

Skąd ten komunikat i co zrobić.

Windows pokazuje ten niebieski komunikat przy aplikacjach nowych lub rzadko pobieranych. Nie znaczy to, że aplikacja jest szkodliwa.

  1. Kliknij Więcej informacji.
  2. Sprawdź, czy wydawca lub nazwa pliku to Kyrofix.
  3. Kliknij Uruchom mimo to.

Pobieraj Kyrofix tylko z halewoodsystems.com. Jeśli masz go skądinąd, usuń go.
