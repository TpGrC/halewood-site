«O Windows protegeu o seu PC»

Porque vê esta mensagem e o que fazer.

O Windows mostra esta mensagem azul para apps novas ou ainda pouco transferidas. Não quer dizer que a app seja perigosa.

  1. Clique em Mais informações.
  2. Confirme que o editor ou o nome do ficheiro diz Kyrofix.
  3. Clique em Executar mesmo assim.

Transfira o Kyrofix só em halewoodsystems.com. Se o obteve noutro lado, apague-o.
